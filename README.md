# 天气战士 · NoneBot2 插件

天气指数小游戏（M2）+ 独立天气查询。天气既是行情原料，也可以单独查。

> 当前状态：M2。已接入真实交易时间（含午休/周末停盘）、连续运行、简化交易、到价买入/平仓、多省同时持仓、保底机制、报价头、同省区域指数。
> 不想玩的时候，直接发 `天气 河北` 就能查天气；收盘后也能用。

## 安装

```bash
uv sync
uv add nonebot-plugin-weather-fighter
```

复制 `.env.example` 为 `.env` 并按需修改。启动：

```bash
uv run python bot.py
```

## 命令

| 命令 | 说明 |
|---|---|
| `天气 [省份/城市]` | 主图截图 + 现在天气 + 今日高低温 + 未来 1 小时；`行情` / `大盘` / `K线` 是同一命令的别名；不用开盘 |
| `买入 [省份] [金额] [倍数 N]` | 做多；金额不填默认 20%；可追加 `倍数 5` / `杠杆 5` |
| `卖出 [省份] [金额] [倍数 N]` | 写金额做空；不写金额默认平仓；可追加 `倍数 5` / `杠杆 5` |
| `到价 [省份] 价格 买入|卖出 [金额]` | 价格触及自动买入/卖出 |
| `到价 [省份] 价格 平` | 价格触及自动平掉该省 |
| `平仓 [省份]` | 平掉该省；不带省平掉全部持仓（只平仓，不主动结算） |
| `撤单` | 取消自己的到价单 |
| `倍数 [N]` | 设置杠杆倍数（1~上限，有持仓时不能改）；不带参数查看当前倍数 |
| `帮助 [省份]` | 命令说明 / 省份详情 |

- **所有群共用一个盘**：所有群共用一条行情时间轴；盘里有很多省，玩家可以随便选省买入/卖出。
- 每个玩家的余额、持仓、到价单互相独立；**可以同时在多个省持仓**，每个省最多一个持仓；账户按群隔离。
- 群成员默认全开，不需要报名/参与；第一次操作时自动建好账户。
- 盘在插件启动时按 `WEATHER_FIGHTER_DEFAULT_PROVINCE` 创建，之后按真实时间自动运行，不需要任何开盘命令；省份可以省略，沿用该群上次选的省。
- 真实交易时间：周一至周五 `09:30-11:30`、`13:00-15:00`；`11:30-13:00` 午休；周末休市。
- **完全按真实时间连续运行，没有盘到期**；发命令时懒补齐到当前真实时间。
- 简化规则：投入多少最多亏多少；不显示手续费/滑点/保证金/强平价/手数；倍数默认 1 倍，可在下单时带 `杠杆 5`，或先用 `倍数 5` 设置；上限由 `WEATHER_FIGHTER_LEVERAGE` 决定。
- 基础行情是 7 天预热 + 30 天窗口；窗口首尾相接滚动，价格在接缝处连续，没有“到期”。每个交易日 16 根 15 分钟 bar。
- 地区当前只开放全国 34 个省级行政区（省会/首府为代表城市）；352 城数据保留在 `regions.json`，后续开放。
- 法定节假日：使用 `chinesecalendar`（随依赖更新，覆盖 2004–2026），节假日休市；超出库覆盖年份时退化为只排除周末。

## 数据与区域指数

- 15 分钟行情：Open-Meteo `minutely_15`（免费、免 key；`historical-forecast-api` 优先）。
- 游戏只保留 A 股交易时段的 bar：每个交易日 16 根；天气查询则直接用完整的 15 分钟实况/预报。
- 区域指数：同省最多 8 城（直辖市取附近城市）等权平均天气，再走同一套 WXI 计算；主图紫色虚线，文字给出数值和构成城市。
- 预报偏离：Open-Meteo `previous-runs` 的「实测 − 提前 24 小时预报」，按窗口中位 + 稳健尺度归一后作为 WXI 冲击项；取不到时按 0。
- 主图预测尾段：取 Open-Meteo 未来 15 分钟气温预报，只用于展示（虚线），不参与 WXI/结算。
- 彩云 v2.6 客户端预留，未配置 token 时不请求。
- 缓存：懒刷新 + 30 分钟桶 + 单飞 + 负缓存 + 旧值兜底；多用户共享同省/同城缓存。
- 第一次买某个省时，加载该省 92 天序列 + 同省区域序列并落盘；之后该省在局中 0 外部行情请求，所有群共享。
- `天气` 命令按 30 分钟桶取一次实况/预报，不影响游戏盘。

## 保底机制

- 每个玩家默认余额 `10,000`（`WEATHER_FIGHTER_PRINCIPAL`）。
- 总资产低于默认余额的 `20%`（2,000）时进入保底；每个真实自然日补默认余额的 `5%`（500），补到 `35%`（3,500）停止。
- 补过头也可以（例如 3,400 补 500 到 3,900）；第二天不再触发，直到再次跌破 20%。
- 离线期间按自然日累计；下次发命令时一次补齐，不需要在线。
- 保底只作用于自己的账户，不影响同群其他玩家；没有盘到期，完全按真实时间连续运行。
- 三个比例都可以通过环境变量调整（见下表）。

## 配置

| 环境变量 | 默认值 | 说明 |
|---|---:|---|
| `WEATHER_FIGHTER_BUCKET_BARS` | 1800 | 15 分钟行情桶（秒） |
| `WEATHER_FIGHTER_STALE_SECONDS` | 21600 | 旧值最多可用时长 |
| `WEATHER_FIGHTER_HTTP_TIMEOUT` | 30 | 单次 HTTP 超时（秒） |
| `WEATHER_FIGHTER_PRINCIPAL` | 10000 | 每个玩家在每个群的初始余额 |
| `WEATHER_FIGHTER_LEVERAGE` | 100 | 杠杆上限（玩家可在 1~该值之间自选） |
| `WEATHER_FIGHTER_SAFETY_ENTRY_PCT` | 20 | 低于默认余额的百分比时进入保底 |
| `WEATHER_FIGHTER_SAFETY_GRANT_PCT` | 5 | 每个真实自然日补默认余额的百分比 |
| `WEATHER_FIGHTER_SAFETY_TARGET_PCT` | 35 | 补到默认余额的百分比后停止触发 |
| `WEATHER_FIGHTER_CHART_BARS` | 64 | 主图节点数（64 根 ≈ 4 个交易日，其中约 15% 为预测尾段） |
| `WEATHER_FIGHTER_ENABLE_REGION` | true | 是否加载同省区域指数 |
| `WEATHER_FIGHTER_DEFAULT_PROVINCE` | 河北 | 启动时用于建盘的默认省份 |
| `WEATHER_FIGHTER_CAIYUN_TOKEN` | 空 | 彩云 token（预留） |

## 主图

主图为单帧 PNG：顶部报价头 + 15 分钟**气温 K 线**（纵轴 ℃、横轴时间）+ MA5/MA20 + 区域指数紫色虚线 + 现价水平线 + 底部活跃量柱；左侧约 85% 是实心红绿的历史气温，右侧约 15% 是空心虚线蜡烛的预报尾段（阴影 + “预测”标注），中间的虚线是当前时刻。WXI 只作为内部波动/影线模型，用户看到的成交价与坐标都是气温。

报价头只使用现有数据：今日最高/最低、体感、全天波动；阵风、降水、湿度、露点；舒适度、天气、CAPE、活跃度、预报偏离；MA5/MA20/区域/区域涨跌；今开、昨收、昨高/低、观测点。当前数据源没有风向、气压、云量、紫外线、日出日落、月相，暂不加入。文字摘要仍单独发送。

- `.github/workflows/ci.yml`：ruff / format / mypy / pytest / build。

## 开发

```bash
uv run ruff check .
uv run ruff format --check .
uv run mypy nonebot_plugin_weather_fighter
uv run pytest
uv build
```

渲染（需要 Chromium）：

```bash
uv run playwright install chromium
```

> 中文字体已随插件打包，不需要系统安装 CJK 字体。
> 插件默认把 `render.provider_config.storage_path` 指向 Playwright 标准缓存（Linux `~/.cache/ms-playwright`），所以 `playwright install chromium` 后即可使用；也可以用 `RENDER__PROVIDER_CONFIG__EXECUTABLE_PATH` 指定现成浏览器。
> 自定义 Chromium 时默认追加 `--no-sandbox --disable-crashpad`；`--no-sandbox` 会削弱浏览器沙箱，只在可信容器内使用。
